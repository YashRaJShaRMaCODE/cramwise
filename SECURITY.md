# Security policy

Cramwise keeps study plans, progress, and notes in the browser's local storage. Never include real learner data, notes, credentials, or backups in a public issue or reproduction; use synthetic data only.

If private vulnerability reporting is enabled for this repository, use **Report a vulnerability** in GitHub's Security tab. Otherwise, contact the repository owner through the public GitHub profile. Include the affected version, impact, and a minimal reproduction with synthetic data.

There is no published response-time guarantee. The app has no account or server-side study-data store; do not send browser backups to anyone unless the learner has explicitly chosen to share them.
